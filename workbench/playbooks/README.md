# Playbooks

Governance Playbooks: practitioner-ready documents assembled by hand from canonical data in `/data`, one topic at a time. This directory deliberately contains no code, no generator, and no template engine — see `FOUNDATION_COMPLETE.md`'s Phase 5 direction: prove the format before building any infrastructure around it.

- [`customer-facing-ai-governance.md`](customer-facing-ai-governance.md) — the first playbook, and the reference implementation every future one is held to.

Each playbook states, at its top, the dataset edition and snapshot date it was assembled from, and every claim inside it cites a canonical object ID that can be looked up in `/data` or the Explorer. A playbook is a view onto the graph, same as the Explorer — see `ONTOLOGY.md`'s Canonical Principle.
